  • Pie Chart — จำนวนผู้ป่วยแยกตามภาค
  • Stacked Bar — ช่วงอายุแยกตามเพศ
  • Filled Map, ค่าเฉลี่ยอายุ, Tree Map
  • Clustered Bar + Filter อายุ 20–29 → ตอบข้อ 3 แล้ว

  1. เปิดไฟล์ Power BI (.pbix) ของสัปดาห์ที่แล้ว ที่ Save ไว้
  2. ถ้ายังตอบไม่ครบ ข้อ 4–6 (หน้า 3) ไม่ต้องกังวล — เดี๋ยวเราจะทำให้ครบกันในสไลด์ถัดไปก่อน
  3. ไฟล์หาย/หาไม่เจอ? ดาวน์โหลดชุดข้อมูลใหม่ได้ที่นี่ → Covid_Round_4_cases.xlsx แล้วเริ่มที่หน้า 5 ของวันนี้ได้เลย
ก่อนอื่นเราจะทำข้อ 4–6 (หน้า 3) ให้เสร็จก่อน — จากนั้นจะสร้างหน้าใหม่ (หน้า 5) ต่อในไฟล์เดิม เรียนรู้เรื่อง Filter และ การทำความสะอาดข้อมูล (Data Cleaning) แล้วตอบคำถามใหม่อีก 4 ข้อ

สัปดาห์ที่แล้วหลายคนตอบได้ถึงแค่ข้อ 3 — วันนี้เราจะใช้เวลาสั้นๆ สร้างอีก 3 กราฟที่เหลือในหน้า 3 (ไฟล์ Power BI เดิม) ให้เสร็จ แล้วค่อยไปเรียนเรื่องใหม่

หน้า 3: ค่าเฉลี่ยอายุ แยกตามภาค

3 ลาก อายุ ไปวางในช่อง X-axis → คลิกลูกศรลง เปลี่ยนเป็น Average
4. ภาคใดมีค่าเฉลี่ยอายุมากที่สุด?

หน้า 3: ความเสี่ยง "สถานบันเทิง" — ภาคไหน เพศอะไร

1 ในหน้า 3 เดิม เลือก Stacked Bar Chart อันใหม่
2 ลาก ภาค ไปช่อง Y-axis · ลากคอลัมน์ใดก็ได้ ไปช่อง X-axis → Count

หน้า 3: หาข้อมูลอายุที่ผิดปกติ (รายจังหวัด)

6. จังหวัดใด ข้อมูลอายุผู้ป่วยมีปัญหา? (ข้อมูลผิดปกติ)
แนวคิด 1 · Filter คืออะไร

Filter — เลือกดูเฉพาะข้อมูลที่สนใจ

จำได้ไหม? สัปดาห์ที่แล้วตอนตอบ ข้อ 3 เราเคยลาก ช่วงอายุ ไปที่ช่อง Filters แล้วติ๊กเฉพาะ 20–29 ปี — นั่นคือการ Filter แล้ว!

Filter คือการ คัดกรอง ให้กราฟแสดงเฉพาะข้อมูลบางส่วน แทนที่จะแสดงข้อมูลทั้งหมด

วันนี้เราจะไปลึกกว่าเดิม: Power BI มี Filter 3 ระดับ ที่ควบคุมพื้นที่ต่างกัน — และมีเครื่องมือใหม่ชื่อ Slicer
แนวคิด 2 · 3 ระดับของ Filter

Filter 3 ระดับ ต่างกันอย่างไร?

ระดับมีผลกับตัวอย่าง
Report level ทุกหน้าในรายงาน กรองเฉพาะปี 2021 ทุกหน้าจะเห็นแค่ปีนี้
Page level เฉพาะหน้าที่กำลังดู หน้า 3 กรองเฉพาะช่วงอายุ 20–29 (แบบสัปดาห์ที่แล้ว)
Visual level เฉพาะกราฟชิ้นเดียว กราฟเดียวกรองเฉพาะความเสี่ยง = สถานบันเทิง
จำง่าย: ยิ่งอยู่แถบ Filters สูง (Report) ยิ่งมีผลกว้าง · ยิ่งอยู่ต่ำ (Visual) ยิ่งมีผลแคบ
เครื่องมือใหม่ · Slicer

Slicer — Filter ที่กดเลือกได้บนหน้ากราฟ

แทนที่จะไปตั้งค่าในแถบ Filters ทุกครั้ง Slicer คือกราฟชนิดหนึ่งที่วางไว้บนหน้า ให้คนดูรายงานกดเลือกกรองได้เอง

  • เลือกไอคอน Slicer จาก Visualizations
  • ลากคอลัมน์ที่ต้องการกรอง (เช่น กลุ่มสำรวจ) เข้าไป
  • คลิกเลือกค่าบน Slicer → กราฟหน้านั้นทั้งหมดกรองตามทันที
ใน Workshop วันนี้: ใช้ Slicer กรอง "กลุ่มสำรวจ" เพื่อดูเฉพาะผู้ป่วยที่เดินทางมาจากต่างประเทศ
แนวคิด 3 · ทำไมต้องทำความสะอาดข้อมูล

Garbage In, Garbage Out

ถ้าข้อมูลตั้งต้น สกปรก (ซ้ำ ขาดหาย เขียนไม่ตรงกัน) — ต่อให้กราฟสวยแค่ไหน คำตอบก็ผิด

  • ข้อมูลซ้ำ (Duplicate) — แถวเดิมถูกนับซ้ำ ทำให้ตัวเลขสูงเกินจริง
  • ข้อมูลขาดหาย (Missing) — บางช่องว่างเปล่า
  • ชื่อไม่ตรงกัน (Inconsistent) — สถานที่เดียวกัน แต่เขียนคนละแบบ
  • คอลัมน์ไม่มีประโยชน์ — ทุกแถวว่างหรือค่าเดียวกันหมด
ตรวจสอบจริง · ไฟล์ COVID ของเรา

ปัญหาที่พบจริงในไฟล์ Covid_Round_4_cases.xlsx

ปัญหาพบเท่าไหร่ทำไมต้องแก้
แถวซ้ำ (Duplicate rows) 157 จาก 1,000 แถว นับผู้ป่วยซ้ำ ทำให้ทุกกราฟสูงเกินจริง ~16%
คอลัมน์ว่างทั้งหมด "job" ว่าง 1,000/1,000 ไม่มีข้อมูลเลย ไม่ควรเก็บไว้ในรายงาน
ชื่อจังหวัดไม่ตรงกัน "กรุงเทพมหานคร" (127) กับ "กทม." (24) ที่เดียวกันแต่ถูกนับแยกเป็น 2 กลุ่ม
อายุ/เพศ ขาดหาย อายุว่าง 110 แถว · เพศ "ไม่ระบุ" 67 แถว กราฟที่ใช้อายุ/เพศ จะไม่นับแถวเหล่านี้อัตโนมัติ
ชวนคิด: ตัวเลขในกราฟสัปดาห์ที่แล้วของเรา (เช่น ภาคอีสาน 280 ราย) ยังไม่ได้ลบข้อมูลซ้ำออก! วันนี้เราจะแก้ให้ถูกต้อง
เครื่องมือ · Power Query Editor

ทำความสะอาดข้อมูลด้วย Power Query

1 แถบ Home → กด Transform Data (จะเปิดหน้าต่าง Power Query Editor)
2 ลบแถวซ้ำ: คลิกขวาที่หัวตาราง (มุมซ้ายบน) เพื่อเลือกทุกคอลัมน์ → Remove Rows → Remove Duplicates
3 ลบคอลัมน์ที่ไม่มีข้อมูล: คลิกขวาที่หัวคอลัมน์ job → Remove Columns
4 รวมชื่อจังหวัดที่ซ้ำกัน: คลิกขวาที่หัวคอลัมน์ จังหวัด → Replace Values → ค้นหา กทม. แทนที่ด้วย กรุงเทพมหานคร
5 กด Close & Apply (มุมซ้ายบน) เพื่อบันทึกและกลับไปหน้ารายงาน
สังเกต: มุมล่างซ้ายของ Power Query Editor จะบอกจำนวนแถวและคอลัมน์ปัจจุบัน — ดูตัวเลขก่อนและหลังลบแถวซ้ำ!

ข้อ 7: ลบข้อมูลซ้ำแล้วเหลือกี่แถว?

1 ก่อนลบ ให้จดจำนวนแถวเดิม (มุมล่างซ้ายของ Power Query Editor ควรขึ้น 1000)
2 ทำตามขั้นตอน Remove Duplicates ด้านบน แล้วดูจำนวนแถวใหม่
7. ก่อนลบแถวซ้ำมีข้อมูลกี่แถว และหลังลบมีเหลือกี่แถว?
หน้า 5 · ข้อ 8

ข้อ 8: รวมชื่อจังหวัดที่ซ้ำกันแล้ว กรุงเทพฯ มีกี่ราย?

1 ทำขั้นตอน Replace Values (กทม. → กรุงเทพมหานคร) ตามด้านบนให้เสร็จ
2 ในหน้า 5 สร้าง Table หรือ Bar Chart: ลาก จังหวัด และคอลัมน์นับจำนวน (Count) เข้าไป
3 หาแถว/แท่งของ กรุงเทพมหานคร — ตอนนี้ควรมีแค่แท่งเดียว (ไม่แยกเป็น 2 แบบเดิม)
8. หลังรวมชื่อ "กรุงเทพมหานคร" กับ "กทม." เป็นชื่อเดียวกันแล้ว ยอดผู้ป่วยกรุงเทพฯ รวมเป็นกี่ราย?
หน้า 5 · ข้อ 9

ข้อ 9: ใช้ Slicer กรองกลุ่ม "เดินทางมาจากต่างประเทศ"

1 ในหน้า 5 สร้าง Clustered Bar Chart: ลาก ภาค ไปช่อง Y-axis · ลากคอลัมน์นับจำนวน ไปช่อง X-axis
2 เพิ่ม Slicer จาก Visualizations → ลาก กลุ่มสำรวจ เข้าไปในช่อง Field
3 คลิกที่ Slicer เลือก "เดินทางมาจากต่างประเทศ" → กราฟ Bar Chart จะกรองตามทันที
9. เมื่อกรองเฉพาะกลุ่ม "เดินทางมาจากต่างประเทศ" ภาคใดมีจำนวนผู้ป่วยกลุ่มนี้มากที่สุด?
หน้า 5 · ข้อ 10

ข้อ 10: สร้างกราฟเพศเอง แล้วเล่า Insight
